# SCI Chain Extensions

SCI Chain customizations on top of Base Azul v0.8.

## Directory Structure

- `crates/` — Rust: Keychain precompile + storage abstractions
- `contracts/` — Solidity: Agent infrastructure contracts (Foundry)
- `gateway/` — TypeScript: MPP Server + REST API
- `devnet/` — Genesis patch + custom allocs
- `docs/` — Project documentation
